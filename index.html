Data Cleaning & Feature Preprocessing Pipeline

This pipeline replicates the exact sequence of data preprocessing operations specified in Cells #3, #4, and #5 of SL_Mini_Project_Semi_Final.ipynb.

1. Index & Artifact Column Removal

Scans dataset headers and removes trailing unnamed index columns (Unnamed: 0) generated during export.

2. Whitespace Normalization & Empty String Imputation

Strips leading/trailing whitespace across column headers and object fields. Replaces blank strings (^\s*$) with NaN.

3. Deduplication Check

Runs df.duplicated().sum(). Verified 0 duplicate entries across the entire 119-player dataset.

4. Numeric Conversion & Comma Stripping

Converts string values like "18,426" to numeric 18426 for columns: Mat, Inns, NO, Runs, Ave, BF, SR, 100, 50, 0, 4s, 6s.

5. Feature Engineering: Highest Score (HS)

Separates the not-out indicator (*) into a boolean feature HS_NotOut and creates a pure numeric score HS_Numeric.

6. Feature Engineering: Career Debut Year

Extracts the starting 4-digit year from career span (e.g., "1989-2012" → Start_Year: 1989) for chronological era grouping.

7. Cleaned Dataset Export

Saves the transformed dataset to cleaned_cricket_dataset.csv ready for model consumption or external download.

2. Pearson Correlation Matrix (df.corr())

Linear Relationships

Measures pairwise linear correlation ($r$) from -1.00 (strong negative) to +1.00 (strong positive). Warmer orange/red shades represent strong positive associations.

💡 Key Mathematical Insights from Correlation:
  • Innings & Runs (r = 0.99): Almost perfect linear collinearity — more batting opportunities directly yield higher run totals.
  • Balls Faced & Runs (r = 0.99): Strongest predictor of run volume, confirming endurance at the crease dictates output.
  • Centuries & Runs (r = 0.91): High positive correlation — century makers consistently dominate aggregate run tables.
  • Strike Rate & Average (r = 0.12): Minimal correlation — fast scorers do not necessarily maintain superior batting averages.
